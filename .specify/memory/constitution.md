# Project Constitution: Data Analysis Portfolio

## Principles
1. **Design Excellence**: The interface MUST look highly polished, premium, and futuristic, following the dynamic styling recommendations from the UI/UX Pro Max skill.
2. **Modern Color Systems**: Colors must use well-defined CSS variables (Light/Dark themes) and feature clean, high-contrast, accessibility-compliant combinations.
3. **Typography**: Use distinct, professional typography (e.g., Google Fonts Space Grotesk + Archivo) that fits the futuristic and analytical mood of data science.
4. **Interaction Quality**: All clickable elements must have appropriate hover, active, and focus states. Emojis must NOT be used as structural icons; use SVG-based vector icons instead.
5. **Responsiveness & Access**: The application must remain fully functional and beautifully aligned at standard breakpoints (Mobile, Tablet, Desktop).

## Governance
- Amendments to this constitution must increment the version number.
- All specifications and implementations must be checked against these principles.
